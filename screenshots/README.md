# Screenshot assets

The root README reserves four slots for screenshots from the English translation build.

Add captures here using these filenames:

- `title-screen.png` — title screen
- `story-dialogue.png` — story dialogue
- `menu-library.png` — a translated menu or Library page
- `battle-scene.png` — battle text or a combat scene

PNG is preferred. Use screenshots captured from your own legally obtained game copy and an experimental project build. Do not add game disc images, BIOS files, or extracted copyrighted assets to this folder.

After adding the images, replace the matching placeholder text in the root README with Markdown image links.
